## 📄 À propos du projet

**PokéNative** est une application mobile développée avec **React Native** et **Expo**. Elle transforme votre smartphone en un Pokédex complet et interactif.

L'objectif de ce projet était de maîtriser le développement mobile moderne en créant une interface utilisateur soignée (UI/UX) capable de traiter des données dynamiques en temps réel.

### ✨ Fonctionnalités
* **Encyclopédie Complète** : Accès à la base de données de tous les Pokémon.
* **Fiches Détaillées** : Visualisation précise des statistiques (PV, Attaque, Défense, Vitesse).
* **Types & Faiblesses** : Affichage des types avec un code couleur dynamique pour une lecture rapide.
* **Interactions Fluides** : Animations et transitions soignées entre la liste et les détails.
* **Recherche Instantanée** : Trouvez n'importe quel Pokémon en quelques touches.

## 🚀 Comment lancer l'appli ?

Puisque c'est un projet **Expo**, c'est très simple de le tester sur ton téléphone ou un émulateur.

1.  **Cloner le projet**
    ```bash
    git clone [https://github.com/Tatanelprr/pokenative](https://github.com/Tatanelprr/pokenative)
    cd pokenative
    ```

2.  **Installer les dépendances**
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement**
    ```bash
    npx expo start
    ```

4.  **Tester sur mobile**
    * Téléchargez l'application **Expo Go** sur votre téléphone (App Store ou Google Play).
    * Scannez le **QR Code** qui s'affiche dans votre terminal.
